## バージョン選定の理由

ユーザーの要望は「最新のカリキュラムではなく、試験の内容が書かれた公開文書（試験範囲・シラバス）をもとに作る」こと。

- **FE / AP**: IPA は 2027年度開始予定の新試験制度向けに「シラバス案 Ver.0.1」（2026年8〜9月掲載）を公開しているが、これは検討中の案で変更可能性が明記されている。本アプリは**現行試験で実際に適用されている確定版シラバス**（FE Ver.9.2 / AP Ver.7.2）と試験要綱 Ver.5.6 を採用した。新制度の案は採用していない。
- **JSTQB FL**: 日本語版シラバスには 2018V3.1.J03（2024年10月の試験まで適用）と 2023V4.0.J02（2024年11月以降の試験に適用）がある。V3.1 系はすでに試験に使われていないため、学習・定着確認の意味がある**現在の認定試験が準拠している 2023V4.0.J02** を採用した。（ISTQB の英語版で今後の改訂があっても、日本語版として公開・適用されるまでは追随しない方針。）
  - 章別出題数（1章8・2章6・3章4・4章11・5章9・6章2、計40問、65%で合格）は ISTQB CTFL v4.0 の試験構成に基づく目安。

## 著作権に関する方針

- IPA の過去問題は IPA の著作物であり、本リポジトリでは使用しない。
- シラバス本文はコピーしない。`syllabus.json` には見出し名（分類名）と ID のみを置く。JSTQB の学習の目的は ID・K レベルと、**独自に要約した短いタイトル**のみ。
- 学習時は原典 PDF を併読することを推奨（アプリ内のリンク参照）。
